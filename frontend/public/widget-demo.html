AgentForge Source on GitHub

Embeddable widget

Put your agent on any page, in that page's own visual language.

One script tag renders a chat panel inside a shadow root, so nothing you already ship can style it by accident and it cannot style anything of yours. What it looks like is a contract of CSS custom properties you control.

shadow DOM 8 theming tokens light · dark · auto no dependencies ~14 kB
The widget in the corner is real code running on this page. Press Play the demo below to watch a scripted exchange — this page has no backend, so the replies are canned, not generated.

Theming

Change a token, watch it land

These controls write CSS custom properties onto the <agentforge-widget> element — exactly what your own stylesheet would do. Nothing is rebuilt or re-mounted.

Install

    
Two tags

    

      Create an API key on the agent's API Keys tab. Scope it with an origin
      allowlist so the key only works from your domain, and give it an hourly rate limit —
      both are enforced server-side.
    


    

      
Minimum

      
    

    
<!-- before </body> -->
<script src="https://your-domain.com/agentforge-widget.js"></script>
<script>
  AgentForge.init({
    apiKey: 'af_your_public_key',
    apiUrl: 'https://your-domain.com/api/v1/public'
  });
</script>


    

      
Everything you can pass

      
    

    
<script src="https://your-domain.com/agentforge-widget.js"></script>
<script>
  AgentForge.init({
    apiKey: 'af_your_public_key',
    apiUrl: 'https://your-domain.com/api/v1/public',

    name: 'Support',              // launcher label and panel title
    subtitle: '',                 // optional line under the name
    placeholder: 'Ask a question',
    welcomeMessage: '',           // empty uses the built-in empty state
    avatar: null,                  // image URL

    position: 'bottom-right',      // or 'bottom-left'
    theme: 'auto',                 // 'auto' | 'light' | 'dark'
    showSources: false,            // name the documents behind each answer
    openOnLoad: false,
    zIndex: 2147483000,

    tokens: {                        // same names as the CSS properties, minus --af-
      accent: '#0e6f7e',
      radius: '10px',
      font: 'inherit'
    }
  });
</script>


    

      Source citations are off. Visitors would see your internal
      filenames and retrieval scores, so the server withholds them from the public
      response unless you turn on Return source citations on the public API
      in Settings — and the widget only draws them when
      showSources: true. Turning off the widget flag alone would be
      cosmetic: the filenames would still be in the JSON.
    

    

      Upgrading? primaryColor and title from the
      previous version still work — they map onto tokens.accent and
      name. Nothing to change unless you want the new tokens.

      <agentforge-widget> element; unset ones fall back to the defaults
      below, which flip with the colour scheme.
